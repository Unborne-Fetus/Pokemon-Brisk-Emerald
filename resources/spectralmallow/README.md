# SpectralMallow Mega sprite sheets

All eight original sheets in this folder are by
[SpectralMallow](https://www.deviantart.com/spectralmallow/gallery).
They are retained as the source for the imports under
`graphics/pokemon/custom_megas/`. Preserve this credit when redistributing.
Battle artwork was extracted from the normal/shiny front/back panels,
scaled proportionally with nearest-neighbor sampling into 80×80 canvases,
and converted to shared 16-color normal/shiny palettes.
The sheet icons and stone artwork remain available in the original PNGs;
in-game stones follow Brisk's existing duplicated-stone asset convention.
